## 紹介文

> 個人事業主や小規模事業者が、公的な仕事を見つけ、仕様書と参加条件を原典で確認するためのWebアプリ。官公需情報ポータルの公式APIから実在案件を収集・蓄積し、IT・Web制作・業務効率化・AI関連の分類で検索できます。

確認できた実装として、キーワードと地域・資料有無の複合検索、公開案件詳細、資料・仕様書の原典リンク、条件の根拠候補表示、スキルとの関連表示、ブラウザー内の条件・しおり保存、日次収集と収集範囲の公開を紹介してください。

技術候補は Next.js 16、React 19、TypeScript、PostgreSQL、Neon、Vercel、Vitest、Playwright。画像には内容が分かる日本語altを付けてください。

注意点として、全国すべての案件を網羅しないこと、参加条件や現在の受付状況は原典で確認することを明記してください。スキル関連表示は参加資格の審査や受注可能性のスコアではありません。APIの入札開始日を応募締切として扱わない設計です。LLMによる仕様書の審査、自動応募・入札・契約、通知配信、ログインや端末間同期を実装済みと記載しないでください。
